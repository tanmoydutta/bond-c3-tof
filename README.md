# bond-c3-tof
A time of flight sensor integrated with ESP32-C3

![alt text](https://github.com/tanmoydutta/bond-c3-tof/blob/main/images/Bond-C3-Mini-VL-ALSv9.png?raw=true)

It also has a matching 3D printed box to house the circuit along with an option to stick a 12x3mm neodymium magnet to stick this to a metallic surface

![alt text](https://github.com/tanmoydutta/bond-c3-tof/blob/main/images/Bond-ToFv11.png?raw=true)
